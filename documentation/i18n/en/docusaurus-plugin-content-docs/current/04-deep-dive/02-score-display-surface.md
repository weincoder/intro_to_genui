# Surface 2: `ScoreDisplay` & Emotional Owl

The `ScoreDisplay` surface is the visual component rendered in **Phase 4 (Final Result)**. It presents the total score achieved, a proportional progress bar, a detailed per-word rubric with semantic feedback, and a retro vector-drawn owl whose emotional mood reacts dynamically to performance.

---

## 🦉 Emotional Owl Mood States (`OwlPainter`)

The app includes a custom Canvas painter ([`OwlPainter`](file:///Users/danielherrerasanchez/develop/gen_ui_flutter_med_fest/intro_to_genui/lib/ui/painters/owl_painter.dart)) rendering a retro owl with expressive pixelated eyes, beak, and wings.

The mood is determined by business logic in the `ScoreMoodUseCase`:

```dart title="lib/infrastructure/driven_adapters/score/score_rules_adapter.dart"
@override
ScoreMood getScoreMood({required double percentage}) {
  // If the user achieved 70% or higher accuracy, the owl celebrates
  if (percentage >= 0.70) {
    return ScoreMood.celebrating;
  }
  return ScoreMood.sad;
}
```

```dart title="lib/ui/widgets/score_display.dart"
class _ScoreOwlMood extends StatelessWidget {
  final ScoreMood scoreMood;
  final double size;

  const _ScoreOwlMood({required this.scoreMood, required this.size});

  @override
  Widget build(BuildContext context) {
    final bool isPassing = scoreMood == ScoreMood.celebrating;
    final String label = isPassing
        ? 'The owl is celebrating 🎉'
        : 'The owl is feeling sad 😢';

    return Column(
      children: [
        SizedBox(
          width: size,
          height: size,
          child: Stack(
            children: [
              Positioned.fill(
                child: CustomPaint(
                  painter: OwlPainter(
                    scenario: isPassing
                        ? OwlScenario.success
                        : OwlScenario.empty,
                    animValue: isPassing ? 0.6 : 0.1,
                  ),
                ),
              ),
              if (!isPassing)
                const Positioned(
                  right: 6,
                  top: 6,
                  child: Icon(
                    Icons.sentiment_very_dissatisfied,
                    color: Color(0xFFE05A7A),
                    size: 20,
                  ),
                ),
            ],
          ),
        ),
        const SizedBox(height: 6),
        Text(label, style: Theme.of(context).textTheme.bodySmall),
      ],
    );
  }
}
```

## 📱 Responsive Layout via `LayoutBuilder`

The surface adapts its visual arrangement according to the available width (mobile vs desktop/tablet):

```dart title="lib/ui/widgets/score_display.dart"
LayoutBuilder(
  builder: (context, constraints) {
    final bool isCompact = constraints.maxWidth < 700;
    final double owlSize = isCompact ? 120 : 170;

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        if (isCompact) ...[
          // Mobile: stacked column layout
          Text(data.title, style: Theme.of(context).textTheme.titleLarge),
          const SizedBox(height: 12),
          _ScoreOwlMood(scoreMood: scoreMood, size: owlSize),
        ] else
          // Desktop / Tablet: side-by-side row layout
          Row(
            children: [
              Expanded(
                child: Text(data.title, style: Theme.of(context).textTheme.titleLarge),
              ),
              const SizedBox(width: 16),
              _ScoreOwlMood(scoreMood: scoreMood, size: owlSize),
            ],
          ),
        // ...
      ],
    );
  },
)
```

## 📋 Detailed Per-Word Breakdown

The `entries` list generated by Gemini is rendered into an intuitive list of `ListTile` items:

```dart title="lib/ui/widgets/score_display.dart"
...data.entries.map(
  (entry) => ListTile(
    contentPadding: EdgeInsets.zero,
    title: Text('${entry.expectedWord} -> ${entry.userAnswer}'),
    subtitle: Text(entry.feedback),
    trailing: Text(entry.score.toStringAsFixed(1)),
  ),
),
```

Each tile presents:
* The expected word vs the user's recall attempt.
* Semantic justification provided by Gemini (*"Exact match"*, *"Semantically related concept"*).
* Points awarded (`1.0`, `0.5`, `0.0`).
